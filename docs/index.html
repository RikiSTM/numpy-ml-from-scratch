numpy-ml-from-scratch

ML Algorithms from Scratch is a machine learning project by RikiSTM, an AI/ML engineer with 10 years of QA experience. It explores fundamental NumPy matrix operations by dissecting and rigorously testing core machine learning algorithms without relying on high-level libraries.

Overview

This project strips machine learning down to its core by learning basic NumPy matrix operations and dissecting fundamental algorithms. It implements Linear Regression, Logistic Regression, L1/L2 Regularization, and Decision Trees entirely from scratch. Every algorithm is accompanied by comprehensive unit and integration tests to ensure mathematical correctness and algorithmic reliability.

Key Techniques

  • Fundamental NumPy matrix operations and vectorization
  • Dissecting and implementing Linear & Logistic Regression from scratch
  • L1 (Lasso) and L2 (Ridge) Regularization implementation
  • Decision Trees implementation with mathematical foundations
  • Unit and integration testing for algorithmic correctness
